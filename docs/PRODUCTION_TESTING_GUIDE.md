### 1. Feature Flag 상태 확인 ✅

**목표**: 현재 활성화된 Feature Flag 확인

**방법**:
```javascript
// 브라우저 개발자 도구 콘솔에서 실행
// 프로덕션 URL 접속 후

// 1. Feature Flags 상태 확인
console.log('Feature Flags:', {
  unified_negodeal: process.env.NEXT_PUBLIC_ENABLE_UNIFIED_NEGODEAL,
  new_navigation: process.env.NEXT_PUBLIC_ENABLE_NEW_NAVIGATION,
  ai_recommendations: process.env.NEXT_PUBLIC_ENABLE_AI_RECOMMENDATIONS
});
```

**예상 결과**:
- 환경변수가 설정되어 있으면: `"true"` 또는 `"false"`
- 설정되지 않았으면: `undefined` (기본값 사용)

**검증 항목**:
- [ ] 콘솔에서 Feature Flag 상태 확인 완료
- [ ] 현재 설정이 의도한 대로인지 확인

### 2. 헤더 네비게이션 확인 ✅

**목표**: 새로운 헤더 메뉴가 올바르게 표시되는지 확인

**테스트 케이스**:

#### Case A: `new_navigation = true` (활성화)
**접속**: 프로덕션 홈페이지
**확인 사항**:
```
✅ 메뉴 구성:
  1. 친구 피드
  2. 네고딜 (✨ Sparkles 아이콘)
  3. 제품 둘러보기

❌ "가격 알림" 메뉴 없음
❌ "공동구매" 메뉴 없음
```

#### Case B: `new_navigation = false` (비활성화)
**확인 사항**:
```
✅ 메뉴 구성 (레거시):
  1. 친구 피드
  2. 공동구매 (TrendingDown 아이콘)
  3. 제품 둘러보기
  4. 가격 알림 (Bell 아이콘)
```

**검증 항목**:
- [ ] 헤더 메뉴 개수 확인 (3개 vs 4개)
- [ ] "네고딜" 메뉴 텍스트 확인
- [ ] Sparkles 아이콘 표시 확인
- [ ] 클릭 시 올바른 경로로 이동 (`/negodeal`)

**스크린샷**: 📸 헤더 메뉴 캡처

```bash

NEXT_PUBLIC_ENABLE_UNIFIED_NEGODEAL="false"  # 비활성화
NEXT_PUBLIC_ENABLE_NEW_NAVIGATION="false"

# 재배포 후 확인
```

- ✅ 에러 없이 정상 동작

**방법 B: 로컬 개발 환경 (localhost)**
```javascript
// 브라우저 콘솔에서
import { setFeatureFlag } from '@/lib/feature-flags';

// 비활성화 테스트
setFeatureFlag('unified_negodeal', false);
location.reload();

// 활성화 테스트
setFeatureFlag('unified_negodeal', true);
location.reload();
```

### 8. 에러 핸들링 테스트 ✅

**목표**: 예외 상황에서 적절한 에러 처리 확인

**테스트 시나리오**:

#### 8.1 네트워크 에러
1. DevTools → Network → Offline 체크
2. 페이지 새로고침
3. 에러 메시지 표시 확인
4. Online 복구 후 자동 재시도 확인

**예상 동작**:
- ⚠️ "네트워크 연결을 확인해주세요" 메시지
- 🔄 자동 재시도 (3회)
- ✅ 복구 시 정상 데이터 표시

#### 8.2 API 에러
1. API 엔드포인트 일시적 장애 시뮬레이션
2. 500 에러 응답 확인
3. 사용자 친화적 에러 메시지 표시

**예상 동작**:
- ⚠️ "일시적인 오류가 발생했습니다. 잠시 후 다시 시도해주세요"
